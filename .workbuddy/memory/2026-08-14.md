# 2026-08-14 工作日志

## 操控方案重构：视角领先+飞机追赶（Ace Combat/War Thunder风格）

### PC端操控改造 (main.js)
- 新增状态变量：aimYaw/aimPitch（视角偏移）、MAX_AIM=0.55rad、TURN_RATE=2.4、PITCH_RATE=1.8
- 鼠标移动→累积到aimYaw/aimPitch（1:1无延迟，clamped to MAX_AIM）
- 飞机以TURN_RATE追赶aim偏移，转向后aim减小（飞机追上视角）
- 慢移：aim偏移小，飞机1帧内追上→感觉1:1
- 快甩：aim偏移打到MAX_AIM，视角先转飞机再追（~0.23秒追上）
- 相机改为跟随视角方向（me.yaw+aimYaw, me.pitch+aimPitch）
- 子弹方向仍用forwardOf（飞机实际朝向）

### 双准星系统 (index.html + main.js)
- 小准星#crosshair：屏幕中心，代表视角方向（34px亮圆+中心点）
- 大准星#planeReticle：偏移显示，代表飞机实际朝向（62px暗圆+虚线内圈）
- 偏移量 = aimYaw/aimPitch * retScale（屏幕短边*0.22）
- 偏移为0时大准星半透明(0.3)，有偏移时更亮(0.8)

### 手机端操控重构 (main.js + index.html)
- 摇杆从单轴(油门)改为双轴(飞行)：
  - Y轴上下 = 加速/减速（原逻辑保留）
  - X轴左右 = 左飞/右飞（joySteerX，连续应用，rate=2.0rad/s）
- setJoy()替代setThrottle()，同时处理dx/dy
- 触屏滑动（steerZone）改为控制视角（同鼠标，累积到aimYaw/aimPitch）
- 摇杆标签"油门"→"飞行"
- nextRound重置aimYaw/aimPitch=0
