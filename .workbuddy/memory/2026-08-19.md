## 联机架构修复（star + 房主转发 + 身份交换）

### 发现并修复的关键 bug
1. **非房主显示点不了的选图界面**：startMapLobby guest 分支隐藏/禁用地图卡片（opacity 0.4 + pointer-events none）
2. **身份 key 不一致（严重）**：主机用 'foe_N' 作连接 key，加入方用自己 myPeerId → 两端 ID 不同，非房主收不到任何状态
   - 修复：加入方 onOpen 发 `{t:'hello', id: myPeerId}`，主机收到后把 nets key 迁移为真实 ID 并分配阵营
   - team 消息带 myId（房主真实 ID）+ gamemode（玩法同步）
   - 加入方收到 team 后也把 nets key 从 myPeerId 迁移为房主 ID
3. **3v3/5v5 非房主看不到其他非房主**：加房主转发 hostRelay（state/fire/died/rematch/ping 广播转发，hit 按 target 定向路由）+ roster 广播（broadcastRoster，hello 后发）
4. **所有消息带 sender 字段**：转发时用 d.sender 识别真实来源
5. **hit 定向路由**：非直连目标走房主：`netSendEventTo(target)` 无直连时带 target 字段发给房主，房主按 target 转发
6. **ping 接收端补全**：onPeerEvent case 'ping' 用 performance.now() - ts

### 友伤
- 'me' 子弹不再跳过友方（planes + aaguns 都打），命中显示"误伤"提示
- AI 子弹 'bot' 照常打玩家实体

### 混合拓扑架构（mesh 直连为主 + 房主转发兜底）
- **建连流程**：房间凑满（最后一个 hello 处理）→ 房主广播 `meshStart`（玩家名单）→ 非房主按 ID 排序（小者发起 offer），SDP 经房主中转（meshOffer/meshAnswer 带 to 定向路由）→ 直连建立
- **链路上报**：mesh 直连成功发 `meshLink`，断开发 `meshUnlink`，房主维护 meshLinks（senderId→Set）
- **自适应发送 sendToAll**：遍历 roster，直连（nets[P].connected）直发，否则 needHost 走房主；房主 hostRelay 转发时跳过 meshLinks[fromPeer] 已直连的玩家（防重复）
- **降级**：mesh 失败/超时（8s checkMeshTimeout）→ 自动走房主转发；1v1 无 mesh（纯 star）
- **去重**：广播消息（state/event）带递增 seq，接收方 lastSeq/lastEventSeq 丢弃重复与乱序
- **关键**：非房主 nets key：nets[hostPeerId]=房主连接 + nets[C]=mesh 直连；wireMeshNet 轻量绑定（不触发 hello/roster）
- 定向消息（hit/mesh 握手）直连优先，未连通走 target 路由

### 关键约定
- 拓扑：star（所有人直连房主），房主转发实现全互通
- nets 字典 key = 对端真实 ID（hello/team 迁移后）
- 消息：state 走 state channel，事件走 event channel；转发原对象（保留 sender）
