## 重赛/退出竞争修复（第十五轮）
- **情形1（先重赛后退出）**：A 重赛进入回合1 → B 退出(reload)掉线 → 旧逻辑判回合1胜后继续空转回合2 → 修复：onPeerClose 检测对手队全员掉线（foeAlive===0）直接结束整场比赛（"对手已全部掉线 · 比赛结束"）
- **情形2（先退出后重赛）**：B 已掉线 → A 点重赛仍开新回合（空地图）→ 修复：btnRematch 前 hasOpponent()（roster 除自己外有无玩家）无对手则拒绝重赛（"对手已离开，无法继续对战"），隐藏重赛按钮
- **时序变体**：B 退出但断线检测延迟时 A 先点重赛 → 仍被情形1修复兜底（进入回合后掉线检测 → 直接结束）
- 3v3 对手部分掉线 → 正常减员结算（foeAlive>0 走原 checkRoundEnd）；practice 模式不受影响
## 3v3/5v5 全员退出重赛漏洞修复（第十六轮）
- **场景1（比赛结束后对方全员退出+本队重赛）**：hasOpponent 旧实现检查"除自己外任何玩家"→ 本队队友也算 → 重赛被允许 → 对方 0 人空地图空转。修复：改为检查**对方队伍**（p.team !== myTeam）
- **场景2（比赛进行中对方全员退出）**：确认无空转——最后一名对方玩家掉线时 foeAlive===0 → 直接结束整场比赛；对方陆续退出（间隔>0.8s）则逐人判回合胜，但最后一人都退时直接整局结束（不进入空回合）
