# 2026-09-03 苍穹对决 v2.2.0 语音通话

## 需求
麦克风语音：一个没用过的键向房主发自己的声音，房主广播（房主也听到）；另一个键停止收音。两键独立→四态（只发不收/只收不发/都开/都关）。码率低能听清即可，定向发送、绝不收到自己的声音。

## 方案（js/main.js）
- 按键：**T=麦克风开/关**、**Y=收音开/关**（keys 无冲突，仅 KeyM/WASD/鼠标已占用）；e.repeat 防长按连触发
- 采样：16kHz 单声道 Int16，40ms/包（640 采样）；JSON 内 base64（net.js 纯 JSON 通道）；净荷 ~32KB/s
- 传输：**state 通道**（不可靠不保序零重传，语音容忍丢包但要低延迟）；自带 seq
- 接收：80ms 重排窗 + 抖动缓冲（首包对齐 nextSeq、迟到丢、80ms 丢包跳进、积压>400ms 重置到 0.2s 保时效）；AudioBuffer(16000) 创建浏览器自动重采样到设备率
- 采集：getUserMedia（echoCancellation/noiseSuppression/autoGainControl）→ ScriptProcessor(2048) → 线性插值重采样 → GainNode=0 静音汇点（Processor 必须连 destination 才工作，但不能外放防啸叫）
- **星型转发防回声（结构性定向）**：非房主 nets 只有房主一条 → sendVoiceChunk 的 for 循环天然定向发房主；房主 onVoiceMsg 转发给其他所有人（id===from 跳过）+ 本地播放；房主自己语音直接广播；from===myPeerId 双保险
- Y 关收音：转发义务照尽（voiceRxOn return 在转发之后）、本地不播
- HUD：右上 pill（🎤开/关(T) · 🔊开/关(Y) · 🗣 讲话者，500ms 超时；net 模式且非默认态才显示）
- 挂接：onPeerState 顶部 `d.t==='voice' → onVoiceMsg(rid,d) return`；removePeerLocal 清 voiceRx/voiceTalk
- 语音仅联机模式可用（practice 按 T/Y 提示）
- 掉线清理：voiceRx 留在缓冲里的包会随 removePeerLocal 删除；AudioContext 懒创建不销毁（复用）

## 版本与校验
- GAME_VERSION v2.1.9→v2.2.0；index.html ?v=1417→1418
- node --check 通过；示意图内联脚本 new Function 校验通过
- 示意图：徽章 v2.1.8→v2.2.0（v2.1.9 漏升）、消息协议卡补 voice 上行/转发 2 行（紫色）、legend 加 voice 紫线、foot 加 T/Y 说明

## 实测方法
1. 联机进入对局 → 按 T 授权麦克风 → 说话，对方应听到且 HUD 显示 🎤开 + 🗣 自己不掉名（自己听不到自己）
2. 按 Y 关收音 → 对方说话自己听不到，但房主转发不受影响；再按 Y 恢复
3. 四态组合：T/Y 各自独立，HUD 实时显示当前状态

# 2026-09-03 苍穹对决 v2.2.1 房主权威击杀台账（kstat）

## 背景与旧机制问题
- 旧：击杀数纯本地预判（子弹命中且致死即 killCount++），房主不下发击杀数据；dmgReject 否决时血量回溯但击杀数不回退（只增不减）
- 巡检发现旧 bug：foeVis 弹（他人子弹）在任意客户端命中致死也会给观看者 killCount++（未排除非自己开的枪）

## 新机制（用户提出：房主列表→汇总→3s 定向下发，完全权威）
- 台账 killLedger：id -> {k:击杀, d:阵亡}，房主端在死亡裁决时记录（整场累计，开赛/重赛清零）
- 归因：模块级 lastDmgFrom（设置→伤害调用→同步死亡判定消费→清空）：
  - 子弹命中：自己的弹=myPeerId，他人弹(foeVis)=b.fFrom；hitRep 宽容结算=rid；信任命中=b.fFrom
  - 碰撞 fatal：互记对方击杀；轻撞 dmg：归因对方；envDmg/died 上报：无击杀者（lastDmgFrom=null）
  - 溅射：applySplashToAAGun 内按 b.src/b.fFrom 归因
- 钩子点：peerDie（两分支）、selfDestruct、selfDestructAAGun → recordAuthKill(lastDmgFrom, victim)
- 下发：pushWorldSync 内 3s 一次，killCount=台账值（房主自己也对账），每人 netSendEventTo {t:'kstat', k, d}（跳过断线）
- 非房主：case 'kstat' → killCount = d.k（权威覆盖）；本地预判 +1 只做即时反馈（≤3s 对账，否决自动纠正）
- 预判击杀计数收紧：2528/2557/379 三处 killCount++ 全部加 b.src==='me' 条件（修 foeVis 误计 bug）

## 校验与产物
- node --check 通过；示意图内联脚本 new Function 校验通过
- 示意图：消息协议卡加 kstat 行（0.33Hz event），徽章 v2.2.0→v2.2.1；index.html ?v=1419
- 已知取舍：预判击杀后若 kstat 先于房主确认到达（RTT 内极小概率），数字短暂 -1 后恢复

# 2026-09-03 苍穹对决 v2.2.3 修复：人机模式击杀 bot 不判胜利

## 根因（用户报告：人机模式击杀后不判胜利）
- 链路：击杀 bot → peerDie('bot') → checkRoundEnd → 0.8s 淘汰倒计时 → settleRound → 回合胜利
- peerDie 的门是 `if (iAmHost) checkRoundEnd()`，而 practice 下 iAmHost=false（只有创建房间才置 true）
  → bot 死亡后 checkRoundEnd 永不调用 → 无淘汰倒计时 → 不结算
- 来源：小世界权威化重构时 peerDie 被收紧为"房主专用"，漏了 practice 口子；对照 selfDestruct 的门是正确的 `mode === 'practice' || iAmHost`
- 注：v2.2.0~v2.2.2（语音/击杀台账/HUD）不是肇因——recordAuthKill 在 practice 下 early-return，未触碰该路径

## 修复
- peerDie 两处分支：`if (iAmHost)` → `if (iAmHost || mode === 'practice')`
- practice 下 recordAuthKill 早退、无台账污染；联机非房主仍不本地结算（权威在房主）✓
- 覆盖路径：狗斗杀 bot 机 / aavs 杀 bot 机 / aavs 杀 bot 防空车 / 溅射杀 bot / 与 bot 同归于尽（双方死 → checkRoundEnd 二次调用 → draw）

## 验证
- node --check 通过；版本 v2.2.2→v2.2.3；?v=1421
