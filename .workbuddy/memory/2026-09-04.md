# 2026-09-04 v2.3.1 修复：人机模式相撞不判平局（判成胜利）

## 根因
- 三处相撞代码（敌机互撞/飞机撞bot防空车/防空车撞bot飞机）有 isBot 偷懒分支：只判 bot 死、玩家存活——与注释"同归于尽（平局）"矛盾，属历史遗留
- 昨天 v2.2.3 修复 peerDie 的 practice 门后，bot 死亡会触发 checkRoundEnd → 只有 bot 阵亡 → 0.8s 后 settleRound('me') → 判"回合胜利"，潜伏矛盾被暴露
- （v2.2.3 之前该分支则完全不结算，回合带着死 bot 无限继续——从来不是真平局）

## 修复
- 三处统一为：iAmHost || practice 路径下 bot 判死（peerDie('bot')）+ 自己判死（selfDestruct/selfDestructAAGun）
  → 第二次 checkRoundEnd 见双方归零 → settleRound('draw') 立即平局（同步，无倒计时竞态）
- lastDmgFrom 归因保持与房主小世界台账一致（互撞互记）；非房主路径不变（上报 crash fatal）

## 验证
- node --check 通过；版本 v2.3.0→v2.3.1；?v=1423
