✉️消息协议（全部经房主）

▲ upd
位置 / 朝向
非房主 → 房主，更新小世界镜像并做撞地/出海权威判死
20Hz · state
▲ fire
开火上报（fid 对账号 + 弹道参数 s/dm/sl）
非房主 → 房主，按开火者实际速度/伤害/溅射重建子弹，权威弹道与本地一致
事件 · event
▲ hitRep
命中上报 {fid, 目标id, 命中点位置, 伤害}
非房主命中后上报；房主信任窗口：子弹到上报点 22m 内且上报点距目标现位置 <60m（防瞬移谎报）→ 信任结算
事件 · event
▼ sync
权威快照（位置/血量/存活/比分 s0/s1/局号 rn/回合结束 over）
已确认的预判自动对账；rn 落后的旧快照整段跳过（防局号回退/二次重置）
20Hz · state
▼ blt
子弹广播（带 s/dm/sl）
房主转发给其他非房主：本地显示 + 被击中预判；开火者凭 from 字段跳过防重复
事件 · event
▼ dmgReject
否决回溯（220ms 延迟否决）
子弹消失后等 hitRep 220ms，过期才否决；已否决 fid 记入黑名单 5s，迟到 hitRep 不双结算
事件 · event
▲ envDmg / crash / died
环境伤害 / 碰撞 / 本地死亡上报
撞地·出界扣血、轻撞 dmg、fatal 相撞（去重键）——权威结算；非房主坠地/出海/自毁也上报 died，房主权威对齐防永久幽灵分歧
事件 · event
▼ rEnd / round
回合结果（rn + s0/s1 + 胜方 w）/ 回合推进
非房主按 w 显示 回合胜利/失败/同归于尽 横幅+音效（与房主一致）；按 rn 幂等重置实体进入下一回合；sync 的 rn 超前同样兜底
事件 · event
▼ matchEnd
终局判定（win + s0/s1）
win 是房主视角：非房主用 s0/s1 按本地阵营换算胜负（比分缺失才兜底取反）——杜绝"双方都看到最终胜利"
事件 · event
▼ ping / pong
延迟测量（回声法）
非房主发 ping(本地时间戳) → 房主原样回 pong → 非房主用自己的时钟算 RTT（两端 performance.now() 基准不同，不能直接相减）；房主不显示 ping
0.5Hz · event
▼ kstat（定向）
权威击杀台账（每 3s 发给对应的人）
房主小世界裁决每次死亡时记台账"谁击杀了谁"（子弹归因开火者 / 相撞互记 / 环境·自毁只记阵亡），汇总成 {击杀 k, 阵亡 d} 定向下发；击杀数以台账为权威覆盖，本地预判 +1 只做即时反馈——被 dmgReject 否决的"预判击杀"在 ≤3s 内自动纠正（不再只增不减）
0.33Hz · event
◈ pickList（定向）
阵营定向分配
选满后房主对每人单独发送"你的队友/对手"视角（例：对玩家A → B是队友、C是对手），确认收到即就绪，无需玩家间校验；掉线强制完成时重发（pickRound 幂等）
开局前
▲ voice
语音上行（T 键开麦，定向发房主）
16kHz 单声道 Int16、40ms/包（640 采样）、JSON 内 base64（净荷 ~32KB/s）——只走 state 通道（不可靠不保序零重传，语音容忍丢包但要低延迟）
25包/s · state
▼ voice 转发
房主转发广播（跳过发送者防回声）+ 本地播放
星型中继：非房主 nets 只有房主一条 → 结构上天然定向、永远听不到自己；接收端 seq + 80ms 重排窗抖动缓冲（丢包跳过不阻塞，积压 >400ms 丢弃保时效）；Y 键关收音 = 转发义务照尽、本地不播
实时 · state

⚡本地预判 + 权威回溯（市售网游模式）

1
伤害/碰撞本地预判：命中先扣血（即时反馈）+ 特效/击杀提示，同时上报 hitRep（带命中瞬间目标位置）预判
2
信任命中（延迟补偿）：房主登记上报点，子弹飞抵上报点 22m 内且距目标现位置 <60m（防瞬移谎报）→ 按上报结算；子弹已消失但未真实命中 → 220ms 窗口内宽容结算补偿
3
房主否决 → 立即回溯：子弹未命中任何目标而消失 → 延迟 220ms 等 hitRep，过期下发 dmgReject，开火者立即恢复预判扣掉的血量；已否决 fid 拉黑 5s 防迟到上报双结算回溯
4
被打对账三层纠错：sync 里已下降的血量 = 已确认预判（自动对账）；未被确认的预判继续预挂；400ms 无权威确认 → 超时回滚，sync 到达后自愈对账
5
死亡权威判定 + 本地即时例外：死亡由房主判定后经 sync 推回；例外：撞海/撞地/出海本地即时判死（体感瞬时反馈），同时上报 died 让权威对齐——否则"本地已死/房主认为存活"会永久幽灵分歧例外
6
复合键防撞号：fid 各玩家独立计数，房主侧一律用 "发送者id:fid" 复合键（fireBullets / 已否决表 / 待否决队列），跨玩家 fid 撞号不会串账防串

🎬对局全流程（进入 → 赢/输回合 → 终局）

1
进入游戏：1v1 房主选图广播 'map'；3v3/5v5 与 aavs 走 选阵营 → pickList 定向发放 → 全员 ready → 'go'。两端各自 beginMatch：清空比分、按 roster 建实体、nextRound(1)（'round' rn 幂等，双发不重复重置）开局
2
赢回合：房主小世界判全歼 → 0.8s 淘汰宽限窗（防同时击杀误判）→ settleRound：s0/s1++ → 广播 rEnd{rn, s0, s1, w} → 3.2s 后 nextRound 广播 'round'。非房主：rEnd 同步比分 + 按 w 显示横幅/音效，'round' 幂等重置实体权威
3
输回合 / 平局：同一条 rEnd 链路，w = 对方队伍 → 本地显示"回合失败"；双归零 w=-1 → "双方同归于尽 · 不计分"。比分以队伍比分 s0/s1 为唯一真相，本地视角换算显示对齐
4
终局：任一队 s≥3 → 房主 matchOver 广播 matchEnd{win, s0, s1}；非房主按 s0/s1 换算自己的胜负（修掉"win 是房主视角"导致双方都看到胜利的 bug）→ 显示 最终胜利/惜败 + 总比分 → 可点重赛终局
5
重赛：任一方点重赛 → 广播 'rematch' → 双方 applyRematch（比分/局号清零，nextRound 从第 1 局重新开始）；对手已全部离开则拒绝重赛防空转循环

📡掉线处理（全阶段覆盖）

1
凑人阶段：非房主视角任何连接断开 = 房主掉线（覆盖 hostPeerId 未赋值的角落）→ 提示后返回菜单；房主侧掉人 → 重算 netSize + 重发 roster，"已连接 x/y" 实时刷新开局前
2
选阵营 / 等就绪掉线：无重连机制，等"重新连接"会永远卡死 → 房主强制完成选阵营：已选的保留、未选的自动补到人少的队（允许 3v2 不对称）→ 重发 pickList（pickRound 幂等）→ 就绪达标立即开局续局
3
奇数人数防死锁：掉线后 5/7/9 人时两队容量 floor/ceil 不对称（如 2/3）；旧版两队同容量会导致总容量 < 人数 → 选阵营永远凑不齐修复
4
对局中非房主掉线：房主清理实体 + 广播 peerGone 各端同步清理幽灵；对手全掉线 → 双端各自独立判定"比赛结束 · 最终胜利"（非房主也感知，不再瞪空地图）；部分掉线 → 视为阵亡走正常回合结算权威
5
对局中房主掉线：星型根断 → 非房主立即结束比赛按阵营判胜负，隐藏重赛按钮（房主不在无法重赛）全员
6
断线归因（中性文案）：WebRTC onClose 双向触发，本端无法区分"对端离线"与"自己断网" → 一律中性提示两种可能；navigator.onLine=false / offline 事件是唯一可靠判据（浏览器自己知道断网），即时提示"你的网络连接已断开"避免冤枉对方归因
7
回合间隙 / 终局面板掉线：3.2s 回合结算窗口内掉线 → 同对局规则处理；终局面板掉人仅清理实体，重赛按钮有 hasOpponent 守卫防空转兜底
8
大厅冻结兜底：非房主 60s 无进展 → "主机长时间未响应"返回菜单（正常掉线由 onClose 秒级处理；兜底不可提前抢跑开局，否则会丢弃 pickList 导致阵营/地图错乱）兜底
