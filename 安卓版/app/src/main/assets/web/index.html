操作说明（安卓版）

✈ 飞机（空战模式）
屏幕滑动 控制视角 / 瞄准（小准星=视角方向，大准星=机头实际朝向，两圈重合即完全跟随）。
左摇杆 上下=加速 / 减速，左右=转向 / 平移；右侧按钮：开火 机炮、瞄准 按住放大。

🛡 防空车（防空作战模式）
屏幕滑动 控制炮塔旋转 / 俯仰，左摇杆 左右=车体转向、上下=前后挪车，右侧开火 双管高射机枪（高射速带散布）。车是固定靶位打法：占好点、卡视野。

⚔ 战场规则
· 撞击即毁：撞海、撞地、撞楼、撞山都是立即爆炸，轻擦友机各扣少量血，飞机撞防空车 / 敌机相撞同归于尽。
· 弱点打击：飞机驾驶舱 3 倍伤害；防空车弹药箱 2 倍、炮塔 1.3 倍（车体血量 120）。机炮打防空车带溅射（近车或落地爆炸范围伤车）。
· 空域限制：飞出边界警告并持续扣血，超高同样警告；多人模式有友军伤害。
· 敌我识别：我方蓝色标记、敌方红色标记，屏幕内外菱形指示器全程追踪；右上角为你的击杀数（房主权威统计）。
· 观战：被击落后若队友还在战斗，自动进入观战视角：滑动环视、点按切换观战对象。
· 语音：右上角「麦克风 / 收听」按钮。首次开启会请求麦克风权限；外放时对方会听到你这边漏出的游戏音效，建议戴耳机。

🌐 联机模式
房主创建房间（1v1 / 3v3 / 5v5）并选择地图（空战二选一：太平洋海岛 / 现代都市；防空作战固定军事基地图），全员同图开局。3v3/5v5 开局前全员选阵营，防空车 1v1 拼手速先抢先得。五局三胜，房主掉线全员判负。

📱 安卓版特色
· 与网页版（game.4365754.xyz）同一套游戏：协议互通，安卓 ↔ 电脑网页版可直接联机对战。
· 纯 WebRTC 直连、无服务器：同一 WiFi 下最稳；跨网络联机建议使用手机热点或接入同一网络。
· 邀请码 / 应答码：长按输入框可呼出系统剪贴板进行复制粘贴；「复制」按钮一键复制整段邀请码。
· 左上角「设置」可调整触屏灵敏度、画质（渲染精度）、阴影与音量。
· 键位布局：设置 →「键位布局」进入调整模式，拖动摇杆 / 按钮 改位置，选中后用滑条改大小，「完成并保存」生效。
· 菜单场景：主菜单 3D 展示可单指拖拽旋转视角、双指捏合缩放（右上角显示倍率）。
· 系统返回键：帮助 / 设置 / 二级面板打开时按返回键直接关闭它们；主菜单按两次退出。
