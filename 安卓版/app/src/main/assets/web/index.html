操作说明（安卓版）

✈ 飞机（空战模式 · 皇牌空战式操控）
左摇杆 = 操纵杆：上推机头下压（俯冲）、下拉拉起（爬升）；左右压杆＝压坡度转弯，杆量越大转得越快。
视角锁定机头，准星就是弹道方向 —— 把目标套进准星开火即可命中，不用再"预判机头"。
加速 / 减速（摇杆上方两个按钮）按住调油门；右侧按钮：开火 机炮、瞄准 按住放大、武器 切换二号武器（火箭炮）。
推杆方向可在 设置 → 上下推杆 切换（默认「上推俯冲」= 航空标准 / 皇牌空战同款；也可改为「上推爬升」）。

🚁 直升机（直升机突袭）
左摇杆：上下 = 前进 / 后退（模拟量），左右 = 左右横移；松开自动悬停。右侧空白处滑动 = 转视角 / 机枪指向，机头会跟着视角缓慢转。
上升 / 下降（摇杆上方两个按钮，进入直升机模式后会自动改名）控制高度；开火 = 机枪（切到炸弹后是投弹）；枪镜 = 机头摄像头视角；武器 在机枪 ⇄ 航空炸弹之间切换。
航空炸弹（左右各一枚）：切到炸弹自动进入机身正上方投弹视角 + 20m 致死环 / 40m 爆炸环落点投影；一次点击投一枚，松开再点投第二枚，投完自动切回机枪。炸弹继承载机速度走抛物线，下坠中会被防空车子弹提前引爆。

🛡 防空车（防空作战模式）
屏幕滑动 控制炮塔旋转 / 俯仰，左摇杆 左右=车体转向、上下=前后挪车，右侧开火 双管高射机枪（高射速带散布），武器 切火箭炮。车是固定靶位打法：占好点、卡视野。

⚔ 战场规则
· 撞击即毁：撞海、撞地、撞楼、撞山都是立即爆炸；飞机之间相撞不分敌我一律同归于尽，撞防空车亦然。
· 弱点打击：飞机驾驶舱 3 倍伤害；防空车弹药箱 2 倍、炮塔 1.3 倍（车体血量 150）。机炮打防空车带溅射（近车或落地爆炸范围伤车）。
· 空域限制：飞出边界警告并持续扣血，超高同样警告；多人模式有友军伤害。
· 敌我识别：我方蓝色标记、敌方红色标记，屏幕内外菱形指示器全程追踪；右上角为你的击杀数（房主权威统计）。
· 观战：被击败后若队友还在战斗，自动进入观战视角：滑动环视、点按切换观战对象。
· 语音：右上角「麦克风 / 收听」按钮。首次开启会请求麦克风权限；外放时对方会听到你这边漏出的游戏音效，建议戴耳机。

🌐 联机模式
房主创建房间（1v1 / 3v3 / 5v5）并选择地图（空战二选一：太平洋海岛 / 现代都市；防空作战固定军事基地图），全员同图开局。3v3/5v5 与防空作战开局前由房主拖拽卡片手动分配阵营（其他人显示等待页），分配完成后自动开始；房主若 45 秒未完成、或期间有人掉线，全员会回到大厅重来。五局三胜，房主掉线全员判负。

📱 安卓版特色
· 与网页版（game.4365754.xyz）同一套游戏：协议互通，安卓 ↔ 电脑网页版可直接联机对战。
· 纯 WebRTC 直连、无服务器：同一 WiFi 下最稳；跨网络联机建议使用手机热点或接入同一网络。
· 邀请码 / 应答码：长按输入框可呼出系统剪贴板进行复制粘贴；「复制」按钮一键复制整段邀请码。
· 左上角「设置」可调整触屏灵敏度、画质（渲染精度）、阴影、音量与上下推杆方向。
· 键位布局：设置 →「键位布局」进入调整模式，拖动摇杆 / 任意按钮（含武器切换、加速、减速）改位置，选中后用滑条改大小，「完成并保存」生效。
· 菜单场景：主菜单 3D 展示可单指拖拽旋转视角、双指捏合缩放（右上角显示倍率）。
· 系统返回键：帮助 / 设置 / 二级面板打开时按返回键直接关闭它们；主菜单按两次退出。
